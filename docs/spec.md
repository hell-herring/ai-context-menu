# 機能仕様（Functional Spec）

> ステータス: **Draft v0.1**（実装前）
> 関連: [技術選定](./tech-stack.md) / [ガードレール](./guardrails.md) / [AGENTS.md](../AGENTS.md)

## 1. プロダクト概要

Webページ上で右クリックするだけで、選択テキストまたはページ本文を AI（Claude / ChatGPT など）に要約させ、結果をブラウザのサイドパネルにストリーミング表示する Chrome 拡張機能。

### 1.1 ゴール

- 右クリック → 1クリックで要約が始まる（設定済みなら追加操作なし）
- 複数の AI プロバイダを切り替えられる（まず Anthropic / OpenAI）
- ユーザーが「何を」「どこに」送ったかが常に分かる（透明性）
- 自前サーバーを持たない（ユーザーのブラウザ ⇔ AI プロバイダの直接通信のみ）

### 1.2 非ゴール（やらないこと）

- 自前バックエンド、アカウント機能、課金、利用状況の収集（テレメトリ）
- AI の Web UI（chatgpt.com / claude.ai 等）の DOM を操作する自動入力
- AI の出力を使ったページ操作・自動実行（エージェント的動作）
- 画像・動画・音声の要約（将来検討）
- Chrome 以外のブラウザ（WXT により Firefox/Edge 対応の余地は残すが MVP 対象外）
- Chrome ウェブストアでの公開（個人利用。ビルド成果物を「パッケージ化されていない拡張機能」として読み込む）
- ローカル LLM・任意のエンドポイント（Ollama、OpenAI 互換 API 等）への対応

### 1.3 動作方式の決定

| 方式 | 概要 | 採否 |
|---|---|---|
| **A. API 直接呼び出し（BYOK）** | ユーザー自身の API キーで拡張から各社 API を呼ぶ | **MVP で採用** |
| B. Web UI への受け渡し | `chatgpt.com/?q=...` 等の URL を新規タブで開く | **MVP には含めない**。Phase 2 以降の候補（URL パラメータ方式のみ。DOM 自動操作はしない） |

A を採用する理由: 公式・文書化された API で安定している／結果を拡張内で表示・再利用できる／長いページ本文を送れる（B は URL 長の制約で本文送信に不向き）。
B はサブスクリプション利用者向けの「APIキー不要モード」として価値があるため、MVP 完成後に再評価する。

## 3. 機能詳細

### 3.1 コンテキストメニュー

拡張アイコン名の親メニュー配下に、コンテキストごとの項目を表示する。

```
AI Context Menu
 ├─ 要約する                  (contexts: selection / page)
 ├─ 3行で要約                 (contexts: selection / page)
 └─ 要点を箇条書き            (contexts: selection / page)
```

- 選択テキストがあれば「選択範囲」、なければ「ページ本文」を対象にする（項目は共通、対象は自動判定）。
- 使用プロバイダ/モデルは設定の「デフォルト」。サイドパネル上で切り替え・再生成できる。
- メニューは `runtime.onInstalled` で登録し、プリセット変更時に再構築する。
- 除外ドメインは **トップレベルのページ URL（`info.pageUrl`）とクリックされたフレームの URL（`info.frameUrl`）の両方**で判定し、どちらかが一致すればコンテンツを取得しない（除外サイトが iframe で埋め込まれている場合の漏れを防ぐ）。クリックされた文書の URL にホスト名がない場合（`about:blank` / `about:srcdoc` 等、親のオリジンを引き継ぐフレーム）は、コンテンツの取得より前にオリジンだけを返す読み取り専用スクリプトを注入し、実際のオリジンと祖先フレームのオリジン（`location.ancestorOrigins`）でも判定する。オリジンを確認できなければ取得しない。
- 除外ドメインに一致するページでは、クリック時に送信せず「このサイトは除外設定されています」をサイドパネルに表示する（メニュー自体は Chrome API の制約上ページ単位で非表示にできないため、クリック時にブロックする）。

### 3.2 コンテンツ取得

| 対象 | 取得方法 | 補足 |
|---|---|---|
| 選択テキスト | `scripting.executeScript` で `window.getSelection().toString()`（クリックされた `frameId` を指定） | 改行を保持するため。失敗時は `info.selectionText` にフォールバック（PDF ビューア等）。**フォーム内の選択は拒否**（下記） |
| ページ本文 | `scripting.executeScript` で拡張同梱の抽出スクリプトを注入し、`@mozilla/readability` で本文抽出 | `document.cloneNode(true)` に対して実行し元 DOM を変更しない。**抽出前にクローンから値を持つフォーム部品（`input` / `textarea` / `select` / `option`）と `contenteditable` の要素を削除**し（`form` 要素自体は残す。ページ全体を `<form>` で囲む ASP.NET 等のページで本文が消えないように）、メール作成欄や CMS エディタの下書きを含めない。**非表示要素も削除する**: クローンでは計算済みスタイルが失われるため、先にライブ DOM を読み取り専用で走査して `getComputedStyle` で非表示（`display: none` / `visibility: hidden` / `hidden` 属性 / `content-visibility: hidden` 等）の要素を特定し、クローンを並行走査して対応ノードを削除する（ライブ DOM は変更しない）。Readability 失敗時は同じ除去済みクローンの本文テキストにフォールバック |

- **フォーム入力値を送らない**: `info.editable === true`（`<input>` / `<textarea>` / `contenteditable` 内の選択）の場合は取得せず「入力欄内のテキストは要約できません」と表示する。注入スクリプト側でも `document.activeElement` がフォーム部品・編集可能要素の場合、選択の始点・終点がそれらの中にある場合、選択範囲が `contenteditable` 要素にかかっている場合（ページ本文の抽出で除去する下書き等を選択経由で送らないため）は、テキストを返さず「編集可能」と返し、background はフォールバックせず同じ表示にする。`info.selectionText` へのフォールバックは、`editable` でなく、注入スクリプトが失敗・不正な値・空の選択を返した場合に限る。
- 権限は `activeTab`（クリック時に一時付与）+ `scripting`。`<all_urls>` の常時注入はしない。
- 取得するメタデータ: タイトル、URL、文字数、取得方法（readability / innerText / selection）、切り詰め有無。
- **プロバイダへ送る URL は `origin + pathname` のみ**（ユーザー情報・クエリ・フラグメントを除去）。署名付き URL やリセットトークン等の漏えいを防ぐため。サイドパネルの表示には元の URL を使ってよい（ローカル表示のみ）。
- 取得不可ページ（`chrome://`、Chrome ウェブストア、`view-source:` 等）では「このページは拡張から読み取れません」と表示。選択テキストのみ `info.selectionText` で要約可能な場合がある。

### 3.3 入力サイズ制御

- 上限は**送信する本文を XML エスケープした後の文字数**で判定する（`&` などが多い本文がエスケープで膨らんでも上限を超えないように）。
- 上限文字数（既定 **50,000 文字**、設定で変更可）を超える場合、**黙って切り詰めない**。サイドパネルで以下を提示する:
  - 元の文字数 / 上限 / 推定トークン数
  - 「先頭から上限まで送信」「キャンセル」
- **モデルのコンテキスト長でも判定する**: 文字数上限とは別に、選択中モデルの入力上限（Anthropic は Models API の `max_input_tokens`、OpenAI はアダプタ内の既知値）とプロンプト全体（system＋本文＋指示）の推定トークン数を比較する。推定は保守的に行い（CJK 文字は 1 文字 1 トークン、その他は 3 文字 1 トークンとして概算し、出力トークン分を差し引いた量と比較）、超える場合は上限超過と同じ確認フローで「モデルに収まる長さまで送信 / キャンセル」を提示する。判定はジョブ受信時・モデル切り替え時・送信直前に行う。それでもプロバイダがコンテキスト長超過を返した場合は専用のエラー文言を表示する。
- 設定「送信前に確認」: `常に` / `上限超過時のみ`（既定） / `しない`（上限超過時は常に確認）

### 3.4 サイドパネル（結果表示）

```
┌─────────────────────────────┐
│ [Claude ▾] claude-opus-5 ▾   ⚙ │ ← プロバイダ/モデル切替, 設定
├─────────────────────────────┤
│ 📄 記事タイトル                 │
│ example.com/article           │
│ ページ本文 · 12,345文字         │ ← 何を送ったかを常に表示
├─────────────────────────────┤
│ ## 要約                        │
│ - ...（ストリーミング表示）      │
│                               │
├─────────────────────────────┤
│ [■ 停止] [↻ 再生成] [⧉ コピー]   │
└─────────────────────────────┘
```

- **ストリーミング表示**: 受信したテキストを逐次 Markdown レンダリング（サニタイズ済み、→ [ガードレール](./guardrails.md)）。
- **停止**: `AbortController` でリクエストを中断。
- **再生成**: 同じ入力で再実行（プロバイダ/モデル/プリセットを変更可）。
- **コピー**: Markdown のままコピー／プレーンテキストでコピー。
- **終了状態の表示**: 完了 / 停止 / 出力上限で途切れた（`max_tokens`）/ モデルが回答を拒否（`refusal`）/ エラー。
- サイドパネルが既に開いていれば、新しいジョブで内容を置き換える（直前の結果は同セッション内の「最近の要約」に最大10件保持、ブラウザ終了で消える）。
- ダークモード（`prefers-color-scheme`）対応。

### 3.5 プリセット（プロンプトテンプレート）

| ID | 名称 | 指示の要旨 |
|---|---|---|
| `summary` | 要約する | 主旨と重要な論点を簡潔にまとめる（見出し＋箇条書き） |
| `tldr3` | 3行で要約 | 3行以内で要約 |
| `bullets` | 要点を箇条書き | 重要ポイントを5〜10個の箇条書きで |

- 出力言語: `ブラウザの言語`（既定）/ `日本語` / `英語` / `原文と同じ`
- Phase 2 でユーザー定義プリセット（名称＋指示文）を追加可能にする。

### 3.6 設定画面（Options Page）

| 項目 | 既定値 | 備考 |
|---|---|---|
| プロバイダ有効化 | Anthropic, OpenAI とも無効 | キー登録で有効化 |
| API キー（プロバイダ毎） | なし | マスク表示。「接続テスト」ボタン（Models API を叩いて検証）。「削除」ボタン |
| モデル（プロバイダ毎） | Anthropic: `claude-opus-5` / OpenAI: `gpt-6-sol`（D-3） | Models API から取得した一覧を**テキスト生成に使えるモデルだけに絞って**表示（OpenAI は埋め込み・画像・音声・モデレーション等を除外。判定はアダプタ内の許可パターンで行う）。手入力も可だが、一覧外のモデルは保存時に警告する |
| デフォルトプロバイダ | 最初にキー登録したもの | キーを登録したプロバイダから選ぶ。選択中のプロバイダのキーが削除された場合は、キーのある他のプロバイダを使う |
| 出力言語 | ブラウザの言語 | |
| 最大入力文字数 | 50,000 | 1,000〜500,000 |
| 最大出力トークン | 8,000 | 256〜32,000 の整数（zod で強制）。選択モデルの出力上限が分かる場合（Anthropic は Models API の `max_tokens`、OpenAI はアダプタ内の既知値）はそれを超える値を保存時に拒否し、リクエスト時も `min(設定値, モデル上限)` にする |
| 送信前に確認 | 上限超過時のみ | |
| 除外ドメイン | 空 | 1 行に 1 つ。`example.com` はそのホストのみ、ワイルドカード `*.example.com` は `example.com` とそのサブドメインに一致する。URL を貼り付けた場合はホスト名を取り出し、小文字化・IDN の Punycode 化をして保存する（ポート・パス付きなど解釈できない行があれば保存しない）。登録例をプレースホルダで提示（銀行・社内ドメイン等）。最大 200 件（`storage.sync` の容量制限のため） |

- 初回インストール時に設定画面を開き、API キー登録と「送信されるデータ」の説明を表示する（オンボーディング）。
- API キー未設定でメニューをクリックした場合、サイドパネルに設定への導線を表示する。

### 3.7 エラーハンドリング

| ケース | 表示 | 再試行 |
|---|---|---|
| API キー未設定 | 「API キーを設定してください」＋設定を開くボタン | - |
| 401 / 403 | 「API キーが無効か権限がありません」 | 不可 |
| 429 | 「レート制限に達しました。しばらく待って再試行してください」 | SDK の自動リトライ後に表示 |
| 5xx / 過負荷 | 「プロバイダ側で一時的なエラー」 | 再生成ボタン |
| ネットワーク断 / タイムアウト | 「接続できませんでした」 | 再生成ボタン |
| コンテンツ取得失敗 | 「このページは読み取れません」 | - |
| 空の選択 / 空の本文 | 「要約するテキストがありません」 | - |
| 除外ドメイン | 「このサイトは除外設定されています」 | - |

エラー表示に API キーやリクエスト本文を含めない。

## 4. 非機能要件

| 分類 | 要件 |
|---|---|
| 対応環境 | Chrome 116 以上（`sidePanel.open()` の要件）、Manifest V3 |
| 配布 | ストア非公開。`pnpm build` の出力（`.output/chrome-mv3`）を `chrome://extensions` の「パッケージ化されていない拡張機能を読み込む」で導入する |
| 性能 | メニュークリック → サイドパネル表示 < 300ms、本文抽出 < 500ms（一般的な記事ページ）。初回トークンまではプロバイダ依存 |
| プライバシー | ユーザーの明示操作なしに外部送信しない。送信先はユーザーが選んだ AI プロバイダのみ。テレメトリなし |
| セキュリティ | → [ガードレール](./guardrails.md) |
| 国際化 | UI は日本語・英語（`chrome.i18n`、既定ロケール `ja`） |
| アクセシビリティ | キーボード操作可能、ボタンにラベル、生成完了時にスクリーンリーダーへ通知 |
| 保守性 | プロバイダはアダプタ追加のみで拡張できる（→ [技術選定](./tech-stack.md#4-アーキテクチャ)） |
